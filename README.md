# Engineering AI Agents: feedback

This repository collects error reports and suggestions for the
[aegean.ai](https://aegean.ai) site and the *Engineering AI Agents* book. It holds
no code. The site's source is private, so reports come here instead.

To report something, use **Report an issue** in the menu at the top of any page.
It opens a new issue here with the page already filled in. You can also
[open an issue](https://github.com/aegean-ai/eaia-feedback/issues/new/choose) directly.

Useful reports name the page, quote the text or describe the figure, and say what
you expected to see.
